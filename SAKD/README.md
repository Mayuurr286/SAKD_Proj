# Semi-Supervised Region of Interest (ROI) Extraction from Remote Sensing Images

This repository contains the implementation of a semi-supervised teacher-student framework designed to accurately extract building Regions of Interest (ROIs) from high-resolution remote sensing images while drastically reducing the need for costly pixel-level annotations.

### Project Overview

* *Objective:* Automate building extraction from complex remote sensing imagery by leveraging large amounts of unlabeled data alongside limited annotations.
* *Methodology:* A confidence-aware knowledge distillation framework where a high-capacity teacher model generates pseudo-labels to guide a lightweight, deployment-ready student model.
* *Efficiency:* Achieves near fully-supervised performance using only 10% labeled data, resulting in a student model that is over 10x smaller in storage size than the teacher (14.25 MB vs. 156.8 MB) and operates with significantly lower computational overhead.
* *Authors:* Jitangsu Chatterjee, Mayur Bhat, Atukuri Nanda Kishan, Arnav Kumar Sinha



### Model Architecture

* *Teacher Network:* SegFormer MiT-B1 (13.68M parameters). Trained via fully supervised learning to provide high-quality soft predictions, global context modeling, and semantic guidance.
* *Student Network:* SegFormer MiT-B0 (3.71M parameters). Trained simultaneously on labeled and unlabeled data using a temperature-scaled KL divergence loss.
* *Advanced Learning Mechanisms:*
* Confidence-Aware Pseudo-Labeling: Filters out unreliable teacher predictions using a confidence threshold ($\tau=0.6$) to prevent confirmation bias.
* Consistency Regularization: Employs weak and strong data augmentations (via Albumentations) to ensure the student learns transformation-invariant features.
* Custom Loss Functions: Integrates Supervised Cross-Entropy Loss, Boundary Loss for sharper ROI delineation, and Feature Adapter scaling ($T=4.0$)





### Dataset

* *WHU Building Dataset:* A benchmark dataset consisting of 5,732 high-resolution RGB images ($512 \times 512$ pixels) with binary building masks.
* *Training Split:* To simulate real-world annotation constraints, the framework uses a randomized 10% labeled and 90% unlabeled data split for training

### Getting Started & Future Work

* *Dependencies:* Built with PyTorch, transformers (Hugging Face), albumentations, timm, evaluate, pandas, and matplotlib.
* *Training Pipeline:* Utilizes PyTorch Automatic Mixed Precision (AMP) and Cosine Annealing learning rate scheduling for efficient, stable training on resource-constrained GPUs.
* *Phase II Roadmap:* Future development will focus on ROI-Based Compression and Efficient Transmission, aiming to lower storage and communication bandwidth requirements for edge computing and UAV deployments
